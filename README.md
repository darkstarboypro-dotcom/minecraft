# Minecraft Vietnamese Translator

Ứng dụng dịch mô tả vật phẩm trong Minecraft sang tiếng Việt

## Tính năng
- Dịch mô tả vật phẩm từ bất kỳ phiên bản Minecraft nào
- Hỗ trợ Mods, Loaders (Fabric, Forge, Quilt, v.v.)
- Chọn cửa sổ Minecraft đang chạy
- Dịch khi di chuột vào vật phẩm
